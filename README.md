# AI 视频内容产线管理系统 (Pipeline Manager)

面向 **AI 视频内容生产**的五层产线管理系统：**产线 → 主题系列 → 剧本 → 提示词 → 素材**。把"面向一类人群、多个主题系列"的视频创作业务做成可管理的产线：每一层都可增删改查、可挂自定义属性、可上传多媒体附件，流程环节**可解耦、可配置**——剧本评审通过才进提示词生产，提示词复核通过才进素材生成，素材（图片/音频/视频/脚本/发布清单）统一归档。

> 纯 Python 标准库（http.server + sqlite3）实现，**零依赖、单文件后端**，低配 VPS 轻松运行。前端为帖子风格的响应式 SPA，桌面/移动端均可顺畅使用。

---

## 为什么需要它？

- **AI 视频创作的生产过程失控**：剧本、提示词、素材散落在文件夹/表格/聊天记录里，找起来靠记忆，版本一多就乱。
- **流程无法卡点**：剧本没评审就进了提示词、提示词没复核就生成了素材——质量不可控。
- **素材没有归档**：每个提示词生成了哪些图片、音频、视频、脚本、发布清单，无法按产出物回溯。
- **一套流程打天下不现实**：不同产线/人群的节奏不一样，需要可配置的流程而非硬编码。

这个系统把"创作产线"结构化：**剧本 →（评审门）→ 提示词 →（复核门）→ 素材**，每层独立管理，环节可增删、可重排、可启停。

## 功能特性

- **五层结构化 CRUD**：产线 / 主题 / 剧本 / 提示词 / 素材，逐层下钻、逐层管理。
- **属性双通道**：每层的核心字段和自定义属性，既支持文本内容，也支持**多媒体附件**（图片/音频/视频/文件，上传/下载/预览）。
- **评审与复核门**：剧本评审（提交/通过/驳回）、提示词复核（提交/通过/驳回），状态流转留痕。
- **流程可配置**：全局默认流程 + 每产线独立覆盖——增删环节、重排顺序、启停环节、设置门点，改完立即生效。
- **帖子风格 UI**：列表为卡片流、详情为帖子式展示，点击展开、填写、上传附件，桌面和手机都好用。
- **附件归档**：按"提示词 → 素材"维度统一管理生成产物（图片、音频、视频、脚本、发布清单等），可下载、可预览。
- **基础鉴权**：环境变量注入 `PIPELINE_ACCESS_USER` / `PIPELINE_ACCESS_PASS` 即开启登录保护。
- **极低占用**：纯标准库，单进程，适配 512MB 内存的 VPS。

## 快速开始

### 环境要求

| 项 | 要求 |
|---|---|
| 运行环境 | Python 3.8+（任意 OS） |
| 内存 | ≥ 256MB |
| 依赖 | **无**（仅标准库） |

### 直接运行

```bash
git clone https://github.com/lovehaichina/ai-pipeline-manager.git && cd ai-pipeline-manager

# 可选：开启登录鉴权
export PIPELINE_ACCESS_USER=admin
export PIPELINE_ACCESS_PASS=你的密码

python3 app.py   # 默认监听 127.0.0.1:8091
```

> 默认只监听 127.0.0.1，需用 Caddy/Nginx 反代对外提供访问（见下）。

### systemd 守护

`/etc/systemd/system/pipeline.service`：

```ini
[Unit]
Description=Pipeline Manager
After=network.target

[Service]
WorkingDirectory=/opt/pipeline
ExecStart=/usr/bin/python3 /opt/pipeline/app.py
Restart=always
RestartSec=3
Environment=PIPELINE_ACCESS_USER=admin
Environment=PIPELINE_ACCESS_PASS=你的密码

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now pipeline
```

### Caddy 反代（自动 HTTPS）

```
pipeline.example.com {
    reverse_proxy 127.0.0.1:8091
}
```

```bash
caddy reload
```

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PIPELINE_ACCESS_USER` | 空 | 开启后需登录（Basic Auth） |
| `PIPELINE_ACCESS_PASS` | 空 | 登录密码（与 USER 同设才生效） |
| `PIPELINE_HOST` | `127.0.0.1` | 监听地址（反代建议保持 127.0.0.1） |
| `PIPELINE_PORT` | `8091` | 监听端口 |
| `PIPELINE_DB` | `./data/pipeline.db` | SQLite 数据库路径 |
| `PIPELINE_ATTACH_DIR` | `./data/attachments` | 附件存储目录 |

附件单文件上限 **100MB**。

## 使用指引（从创作视角）

1. **建产线**：一个产线 = 一类粉丝画像人群（如"宝妈育儿""健身人群"）。填写产线名称、描述、自定义属性。
2. **建主题系列**：每个产线下多个主题（如育儿产线 → "辅食""睡眠""早教"）。同样可挂自定义属性与附件。
3. **写剧本**：每个主题下多个剧本，提交后进入**评审门**——评审通过才可进入提示词环节。
4. **生产提示词**：剧本评审通过后创建提示词（可手动录入，也可由 AI Agent 生成后回填），提交复核。
5. **归档素材**：提示词复核通过后，将大模型生成的图片、音频、视频、脚本、发布清单等作为**素材**挂到该提示词下，可上传文件、可预览、可下载。
6. **流程配置**：在设置中调整全局流程或单个产线的环节顺序/启停/门点，流程变更不影响已有数据。

> 剧本生成提示词、提示词生成素材的动作本身不在此系统内——由你的 AI Agent 完成生产后，通过接口或手工回填到系统统一管理。

## 常见问题

**Q：如何接入我的 AI Agent 自动生产？**
系统提供标准 CRUD 接口；你的 Agent 完成剧本生成 / 提示词生成后，调用对应接口写入数据、更新状态即可（接口形态见 `app.py` 中路由定义）。

**Q：流程环节可以改吗？**
可以。全局默认流程 + 每产线独立覆盖，增删、重排、启停、设置门点即时生效，历史数据不受影响。

**Q：附件支持哪些格式？**
任意文件类型（图片、音频、视频、压缩包、文档等），单文件 ≤ 100MB，支持预览（浏览器可渲染的类型）与下载。

**Q：适合多大团队？**
个人 / 小团队（≤20 人）完全够用；纯标准库实现，性能瓶颈取决于机器。
